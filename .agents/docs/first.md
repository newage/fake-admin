frontend/ це адмінка. приклади стилів адмінки зображені в admin-styles/
Рекомендований стек

Vite + React + TypeScript + Tailwind CSS + shadcn/ui, а поверх нього:

TanStack Router: маршрути, захист сторінок, стан таблиць в URL.
TanStack Query: запити до API.
TanStack Table: таблиці.
React Hook Form + Zod: форми.
Recharts через shadcn Charts: лінійні й кільцеві графіки.
lucide-react: іконки.

Опис дизайну
Акцент	Пастельний зелений, чорні основні кнопки
Графіки	М'які пастелі, сірий «фон-доріжка» стовпців, площина під лінією
Картки	Великі радіуси, майже без тіней, легка рамка
Сайдбар	Плоский, активний пункт як «пігулка» з білим фоном, бейджі лічильників
Іконки	Контурні, у кольорових «плашках» біля заголовків
Щільність	Дуже повітряна

backend/ це API, PHP8.4 + Mezzio, phpunit і behat.
бекенд читає данні з БД для виводу в форматі JSON в API
JWT авторизація і RBAC (яка роль яку япі може викликати, з якими параметрами)

docker/ тут всі докер файли, локально розробка тільки в докер. nginx + fluent-bit для збирання логів
