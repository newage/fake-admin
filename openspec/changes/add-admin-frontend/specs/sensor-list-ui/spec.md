# Spec Delta

## Purpose

Описує екран адмінки зі списком датчиків: таблицю над серверним API, стан таблиці в URL, порожній стан і помилку завантаження.

## ADDED Requirements

### Requirement: Екран списку датчиків
Адмінка SHALL показувати таблицю датчиків зі сторінками, сортуванням і фільтрами, а стан таблиці (сторінка, сортування, фільтри) SHALL зберігатися в URL.

#### Scenario: Відновлення стану з URL
- **WHEN** користувач відкриває посилання зі збереженими параметрами сторінки й фільтрів
- **THEN** таблиця показує той самий зріз даних

#### Scenario: Порожній результат
- **WHEN** фільтр нічого не знайшов
- **THEN** екран показує повідомлення «нічого не знайдено» і спосіб скинути фільтри

#### Scenario: Помилка завантаження
- **WHEN** запит списку завершується помилкою
- **THEN** екран показує повідомлення про помилку з можливістю повторити
