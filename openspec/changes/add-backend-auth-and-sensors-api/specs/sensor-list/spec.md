# Spec Delta

## Purpose

Дає авторизованим ролям змогу переглядати каталог датчиків: серверний список із пагінацією, сортуванням і фільтрами та екран адмінки над ним.

## ADDED Requirements

### Requirement: Пагінований список датчиків
`GET /api/sensors` SHALL повертати JSON зі сторінкою датчиків, загальною кількістю й параметрами сторінки; список SHALL завжди пагінуватися з обмеженим розміром сторінки.

#### Scenario: Сторінка за замовчуванням
- **WHEN** авторизований `admin` викликає `GET /api/sensors` без параметрів
- **THEN** відповідь містить не більше розміру сторінки за замовчуванням (25) елементів, `total`, `page`, `page_size`

#### Scenario: Завеликий розмір сторінки
- **WHEN** клієнт просить `page_size` більше максимуму (100)
- **THEN** запит відхиляється з 422 або розмір обмежується максимумом, весь список не повертається

### Requirement: Поля елемента списку
Кожен елемент SHALL містити `id`, `code`, `name`, `type`, `unit`, `device_id`, `location`, `status`, `created_at`, `last_seen_at` і SHALL NOT містити секрет датчика чи його версію.

#### Scenario: Секрети не витікають
- **WHEN** клієнт отримує список
- **THEN** у відповіді немає полів `secret_enc` і `key_version`

### Requirement: Сортування
Список SHALL підтримувати сортування за `name`, `code`, `created_at` у напрямку asc/desc; інше поле сортування SHALL відхилятися.

#### Scenario: Сортування за назвою
- **WHEN** клієнт просить `sort=name&order=desc`
- **THEN** елементи йдуть за спаданням `name`, з `id` як стабільним другим ключем

#### Scenario: Недопустиме поле
- **WHEN** клієнт просить `sort=secret_enc`
- **THEN** відповідь 422

### Requirement: Фільтри
Список SHALL підтримувати фільтр по `name` і `code` (точний збіг або префікс від 3 символів) та діапазон за `created_at`; коротший префікс SHALL відхилятися.

#### Scenario: Префікс коду
- **WHEN** клієнт просить `code=TMP`
- **THEN** повертаються датчики, чий `code` починається на `TMP`

#### Scenario: Занадто короткий префікс
- **WHEN** клієнт просить `name=te`
- **THEN** відповідь 422

#### Scenario: Діапазон дат
- **WHEN** клієнт задає `created_from` і `created_to`
- **THEN** повертаються лише датчики, створені в цьому діапазоні

### Requirement: Доступ до списку
Список SHALL бути доступний ролям `admin` і `manager` згідно з матрицею прав.

#### Scenario: Ролі без права
- **WHEN** користувач без права викликає `GET /api/sensors`
- **THEN** відповідь 403
